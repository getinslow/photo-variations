# 选中后怎样执行

这里只做集成适配，视觉规范仍以上游入口和原始参考文档为准。七个工作流原文随包保留，极简抽象从固定版本的原仓库读取；入口改名、外部引用和资源裁剪记录在包清单里。

## 所有路线

最终交付前执行 [不可见署名](attribution.md)：完成生成、审图、拼版/优化及本页要求的清理后，使用真实选中的工作流写入 `创作者×变奏` 元数据并读回验证；交付署名后的文件，不在生图提示词中要求可见水印。

工作流执行是 agent 读取选中流程并实际使用宿主的生图/图片编辑能力，不是 Python 动态调用另一 Skill。`route_photo.py` 提供的是选中路径和决策记录。将观察到的辨识特征写进生成请求；调用时明确照片是参考或编辑目标。提示词中不写磁盘路径、路由内部信息或授权记录。

默认一张作品，保留该款原始比例；用户指定的比例优先，但不能破坏该款必要版式。宿主工具、文件边界和用户授权优先于上游的默认保存目录。写到用户指定项目；没有指定时用工具返回的非覆盖路径。不要硬编码某台机器的绝对路径。

原工作流有“只输出作品”或“同时输出配方”的差别；本整合 Skill 的用户体验统一为图片加一句原因。完整提示词/配方可以放进本次执行记录，用户索要过程时展示。

## 水彩与厚涂

生成完整 3:4 作品；照片只作参考。水彩保留档案边栏和圆孔分隔，厚涂保留堆叠油彩与微缩支撑带，不能混成一个普通水彩/油画滤镜。新增标题从可观察主题取材，无未经证实的地名、坐标或日期。

## 纸上留影

先完整读 `references/afterimage-editorial-prompt.md`。摄影区真实且不重画、调色或扩展；下方提炼完整主体关系。生成工具无法保证像素相同时，不声称像素级原片保留；用户要求像素完全不变时，要有能把原图直接放回摄影区的宿主拼版工具。没有该能力则停在需要拼版的状态。

## 小人互动

自动模式已明确选择普通海报的“无新增文案”方向，因此不再出现上游的三选一菜单。读取 style-guide 和 evaluation。多独立主体规则仍保留；只有用户明确选了主角才可隔离其中一个。

本路由的默认是 **不新增标题、字母、数字或伪文字，保留源照片原有可读文字**。这是对上游严格“无字版”的明确集成调整：用户帽子、包装等原有文字属于摄影主体，不擅自抹除。若用户明确要完全无字，需要说明与原物保真的冲突并确定处理范围。不要将此适配说成原版无字规范。

人物、食物或物件保持真实摄影，只在留白安排一个粗糙黑线微型工人的动作；不要重造脸、改变手指/控制器、把整幅图变成卡通。带字版另读 lettering-guide，按原两段标题流程执行。没有标题脚本依赖时优先用宿主已有排版/生图能力，不安装桌宠环境。

## 单色/双色印刷

按原入口读取 `design-system/` 所需六个目录，目录数值优先。默认受控双色；用户说单色才用一版。仍保留至少一个主题辨识关系、网点/版分离和纸面露白，不能只套一层色滤镜。默认现代编辑排版，不自动做旧。原默认 Claude 桌面保存位置在本整合中由宿主项目目录替代。自制色板属于资源，作者示例和第三方参考图未打包，不作为运行必要条件。

## 拾景与极简抽象

先检查使用语境/对应授权。拾景读取内置原文；极简抽象先读 [外部索引](external/photo-abstract-editorial.md)，再通过联网文档工具完整读取固定版本的上游入口、中文提示词与许可。不能把网上“允许非商业使用”表述成已取得源码再分发授权。上游读取失败时，不凭本适配说明代替完整原文。两者不能用同一种纸纹与撕边模板。

## XXD

先检查许可和 `xxd-strip-ai-meta` 执行能力：本包在 `references/helpers/xxd-strip-ai-meta/` 保留了固定提交的完整辅助入口、脚本、说明和 MIT 许可，但宿主仍须有 Python 3.10+ 与 ExifTool。只有真实检查通过才将该名称标为 available_workflows。完整读取中文 original-prompt 与 soldier-runtime，原文拼接创意 brief，不翻译、不压缩、不另加整合包配色。单图自动接口明确采用 `top-bottom`、整幅 `3:4`、严格上下 `50:50`、一张 PNG、无新增文字；这些是本入口定义的自动参数，用户明确的模式/尺寸/文字覆盖它们。选择前要表明这些默认参数，不静默继承照片比例。上半原照可按原 brief 轻调色和自然延展背景，但不改变主体；要求严格原片时在其参数中明确。

输出使用用户项目的显式 `--out` 根及新的任务目录。不自动联系配置外服务，不安装第三方生图后端。原入口提到的缺失 `original-prompt/README.md` 是翻译索引，本包不依赖它。

发布前读取内置辅助 `UPSTREAM.md`，只对本次新生成图的明确路径执行它的脚本，保留默认 ICC、验证和 `--backup`，单张建议 `--jobs 1`。不要把用户原图或历史输出目录交给原地清理。确认发现数量、成功/失败/跳过数量和验证结果；退出码 0 不代表找到了图片。不存在执行能力时这一路线不具备完整交付条件，不用未经确认的替代脚本冒充。清理仅涉及支持的元数据，不能被描述成清除可见/像素水印或“非 AI 图片”。宿主若要求图片操作只能通过特定工具，该工具边界优先，缺少合规清理能力就报告依赖不足。
