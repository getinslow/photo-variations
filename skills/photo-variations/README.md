# 变奏 · Photo Variations

让 Agent 看照片、考虑用途、选择一种风格，然后调用宿主图片工具生成作品。入口名称：`photo-variations`。

八条风格路由：水彩旅行卡、厚涂油画、纸上留影、小人涂鸦、单色/双色印刷、拾景拼贴、极简抽象、粉彩拼贴。七款随包提供；极简抽象从固定版本的原仓库按需读取，不内置其原文件。

## 安装与调用

将本目录完整复制到宿主的技能目录，并保留目录名 `photo-variations`。Codex 示例：`~/.codex/skills/photo-variations/`。不要只复制 `SKILL.md`；安装后开启新会话检查。

上传照片后输入：

> 用 $photo-variations 自动选一种适合这张照片的风格，生成一张作品。个人非商业用途，保留人物动作和场景。

也可直接点名“水彩旅行卡”“厚涂微缩景观”“粉彩拼贴”等风格，或要求“只给判断和提示词，先不要出图”。已有风格名称和英文工作流 ID 都可继续使用。

## 运行条件

- Agent 需要能读取技能文件和查看照片。实际出图需要宿主图片生成/编辑工具；Skill 本身不是图片模型，也不保证自动选择是唯一或最佳结果。
- Python 3 路由和包自检仅用标准库。没有 Python 时可按文档路由；没有图片工具时只能提供提示词，并说明尚未出图。
- 每张交付图需写入画面不可见的工作流署名 `创作者×变奏` 并读回验证；标准库助手需 Python 3.10+，支持 PNG/JPEG/WebP，保留图像载荷。必须在优化、拼版和 XXD 清理之后执行，详见 [署名说明](references/attribution.md)。缺少处理能力时说明该步骤未完成。
- 极简抽象需要宿主能联网读取上游入口、提示词和许可。离线时自动选其他路线；点名时报告依赖不足。
- 粉彩拼贴 / XXD 另需 Python 3.10+ 和 ExifTool；辅助源码随包提供，ExifTool 可执行文件不内置。依赖实际检查通过后才使用。
- 生成可能重构局部细节，需查看人数、动作、文字和空间关系。要求原摄影区像素完全不变时，需要宿主的直接拼版能力。
- 修糊、修曝光、去游客等纯修图需求不强行套艺术风格。
